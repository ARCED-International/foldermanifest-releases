# FolderManifest — Desktop App Releases

**Know exactly what's in any folder. Instantly.**

FolderManifest scans any directory and generates a complete manifest — every file, size, checksum, and structure — so you can audit, verify, and prove folder integrity across time and machines.

## What it does

| Feature | Detail |
|---|---|
| **Folder scan** | Recursive scan of any directory, any size |
| **Checksums** | CRC32 (fast) or SHA-256 (verified) per file |
| **Multiple formats** | Export as HTML, CSV, or Markdown |
| **Verify** | Compare current folder against a saved manifest — find added, removed, or changed files |
| **Duplicate finder** | Detect duplicate files by checksum across a directory tree |
| **CLI** | Full command-line interface for scripting and automation |
| **Offline** | Runs entirely local — no cloud, no account needed to scan |
